# NyumbaLink

Responsive landing page recreated from the supplied mobile reference video.

## Files
- `index.html` — page structure and content
- `style.css` — responsive desktop/mobile styling
- `script.js` — county/town filtering, rent/land toggle, search feedback, listing modal and FAQ modal

## Run
Open `index.html` in a browser.

No build step is required. The Google Fonts import requires internet access; the site will still work with a system sans-serif font if it is unavailable.

## Backend
The property search and "Post property" form are currently front-end interactions. Replace the JavaScript handlers with your API calls when connecting this to Flask, FastAPI, Node.js, etc.


## About section
The About section now contains the NyumbaLink logo/description, Popular Areas (Ruaka, Kitengela, Syokimau, Nyali), and Platform links (Landlord sign up, Browse listings, Sign in), matching the supplied mobile reference.
